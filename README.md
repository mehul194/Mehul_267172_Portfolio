# Mehul Sharma Portfolio

A simple responsive portfolio made with HTML, CSS, and JavaScript.

## Run locally
Download or extract the files, then double-click `index.html` to open it in your browser.

## Publish on GitHub Pages
1. Create a GitHub repository named `mehul-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages.
4. Choose Deploy from branch: `main`, folder `/ (root)` and Save.
